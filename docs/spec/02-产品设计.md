## 当前阶段 · 好用

开源用户克隆后应感到「能正经用」，而非 demo。当前阶段须达成：

**P0（与本地 Embedding 同期）**

- 管理页 **仅配 Chat 三项**；Embedding 显示「内置本地，无需配置」。
- 部署文档（README + Docker）清晰；默认管理员可完成首问。
- `e2e-smoke` + `e2e-answer-quality` 在本地 Embedding 下仍通过（阈值可重标）。
- 问答能力边界写清（见「问答 · 能力边界」），避免「总结 10 份文件 = 覆盖 10 份」的误解。

**P1（好用迭代，按优先级实现）**

- **概括/总结/能力类问法**扩展识别（含「总结已上传材料」「文档主题」等），Prompt 短答并声明「仅依据检索到的段落」。
- **多文件检索**：在 top-K 内尽量 **每文件至少 1 段**（当 ready 文件数 ≤ K），减少 8 段全来自同一文件。
- **分块改进**：至少 Markdown 保留段落/标题边界再切（不再一律压成一行硬切 500 字）。

**P2（更远，规格先占位）**

- 检索 rerank（top-N 重排再取 K）。
- 多文档 Map-Reduce 总结（若产品承诺「一次总结 N 份全文」）。

## 主路径 · 自托管 Web（当前）

1. 打开入口页：左侧品牌 + 右侧**仅登录**（无公开注册、无忘记密码）。
2. 管理员进 `/admin`：改密、配 **Chat**、创建/重置/删除普通用户。
3. 进入工作台：上传文档，看到「处理完成」或失败原因。
4. 提问（可选限定部分 ready 文件）；看回答与可点出处。
5. 再次访问：有登录态则直达工作台。

## 三态

### 自托管（当前）

- **部署者首次：** README 起服务 → 默认管理员登录 → 管理页改密、配 **Chat** → 可选建用户 → 上传 → 首问。
- **普通用户：** 登录 → 工作台；忘密由管理员重置。
- **Chat 未配置：** Toast「请在管理页填写 API Key、Base URL 与对话模型。」
- **Embedding：** 本地模型未就绪（部署错误）：上传/提问失败，提示检查部署/模型文件（文案待实现时定）。

**账号失败（仅自托管）：**

- 登录失败：「账号或密码不对。」
- 用户名不合法：「用户名格式不对（2–64 位，仅字母数字及 @._-）」
- 密码太短：「密码至少 6 位。」

### 桌面 **（远期）**

- 首次 `/setup` 配 Chat → 工作台；未配齐不可进工作台。

### 共用失败（用户文案）

- 文件类型不对：「只支持 PDF、Word、PPT、Excel、CSV、Markdown 和纯文本。」
- 太大：「每个文件不超过 20MB。」
- 上传没成功：「文件没传上去，请再试一次。」
- 解析失败：「这份文件读不出来，请换一份或另存为支持的格式再试。」
- 处理中刷新：「还在处理，请稍候。」
- 检索支撑不足等：阅读流内「抱歉，我在您上传的材料里没有找到足够依据…」**不用顶部 Toast**

## 对象与规则

- **资料库：** 单用户一份；自托管按登录用户隔离。
- **文件：** 支持 `.pdf`、`.md`、`.txt`、`.docx`、`.pptx`、`.csv`、`.xlsx`；单文件 ≤ 20MB；无数量上限。不支持 OCR、老版 `.doc`。
- **存储：** 原文件在 `FILES_DIR` 本地磁盘。
- **Embedding（当前）：** 入库与提问检索均用**内置本地模型**；切片用 `passage:` 前缀，提问用 `query:` 前缀（E5 惯例，见 `04`）。
- **Chat：** 仅生成答案；须管理页配齐 Key / Base URL / 对话模型。
- **问答 · 能力边界：** 每一问独立检索，依据 **最多 K 段** chunk（默认 8，见 `04`）生成答案；**不承诺**一次覆盖用户全部文件或全文总结。概括类问法须说明「仅依据下列检索段落」。多文件全面总结属 P2（Map-Reduce）或引导用户分文件/限定 `fileIds` 提问。
- **问答 · 检索：** 只检索 ready 文件；可选 `fileIds` 限定。是否可答看检索分数 + Prompt；支撑不足走「材料里没有」。
- **对话：** 多会话；新建/切换/重命名/删除；删除不删文件。
- **出处：** 关键结论须文件名 + 片段。
- **世界知识：** 禁止；仅允许「材料里没有 / 依据不足」。
- **语言：** 系统文案中英；材料与出处不翻译。

## 产品层（地板）

### 自托管 Web（当前）

- **账号：** 种子管理员；管理页建用户、改密、重置、删用户。
- **登录名：** 2–64 位，小写；`[a-z0-9@._-]`。
- **密码：** 新建/重置 ≥ 6 位。
- **隔离：** 按 `user_id` 过滤。
- **模型配置（管理页 · 模型 Tab）：** **必填三项**——API Key、Base URL、对话模型。Embedding 为内置本地，**不要求用户填写** Embedding 模型名与向量维度；页内只读说明即可。

### 桌面安装包 **（远期）**

- 无账号；隐式单用户；`/setup` 仅配 Chat。

### 共用

- **隐私：** 入口左栏一句：上传文件只用于生成回答，不作其它用途。
- **语言：** 第一版仅中英。
