# 技术设计 · 问牍

## 方案概述

浏览器走 Vue 页面；FastAPI 管登录、上传鉴权、去重、解析切片、检索、生成。Postgres 存用户、文件元数据、切片、问答、实例级 **Chat** 配置。原文件落在部署机本地磁盘；浏览器短时签名 PUT 到 `/api/storage/...`。提问时：检索该用户已完成切片（**本地 Embedding** + Postgres FTS）→ 片段不够则「材料里没有」→ 够则 **Chat** 流式生成带出处编号的回答。

支持的文档扩展名：`.pdf`、`.md`、`.txt`、`.docx`、`.pptx`、`.csv`、`.xlsx`。Office/表格抽纯文本再切片；不做 OCR。

## 当前阶段 · 实现范围

| 项 | 当前 | 远期（规格保留） |
|----|------|------------------|
| 交付 | 自托管 Web only | 桌面安装包 |
| 身份 | Cookie 登录 + 管理员 | `DEPLOYMENT_MODE=desktop` 隐式用户 |
| Embedding | **内置本地**（见下） | 同左，随包分发 |
| Chat | 管理页配置 | 桌面 `/setup` |
| 代码分叉 | **无** desktop 分支 | 身份层 + 路由 |

**原则：** 当前所有开发围绕自托管；RAG/ingest/files 不写 `if desktop`。

## 交付形态（技术）

- **自托管（当前）：** Docker Compose 或本机进程；Cookie 登录；`/auth`、`/admin`、完整工作台。
- **桌面（远期）：** 见下文「部署模式 · desktop」；**当前不实现**。
- **明确不做：** 多租户 SaaS、第二套 RAG 后端。

## Embedding · 本地（当前阶段目标）

- **模型：** 默认 **`multilingual-e5-small`** 等价能力（ONNX 或 Python 推理；模型文件随部署包或 Docker 镜像，路径可 `TEXT_EMBEDDING_LOCAL_PATH` 覆盖）。
- **维度：** **384**（与 e5-small 一致）；`chunks.embedding` 与 pgvector 列按此维度；**切换模型须重 ingest**。
- **前缀（E5 惯例）：** 切片 `passage: {text}`；提问 `query: {text}`。
- **调用：** `ingest` 批量 embed；`rag.retrieve` 对问题 embed；**不走云端 `/embeddings`**。
- **配置：** 用户**不**在管理页填写 Embedding；模型与维度由代码/`config` 固定，不入库。

## Chat · 云端（当前）

- OpenAI 兼容 `POST .../chat/completions`（流式）。
- 管理页必填：**API Key、Base URL、对话模型**。
- 读 `instance_settings`；缺项 → `LLM_NOT_CONFIGURED`（仅影响 Chat，不影响本地 embed）。

## 部署模式 · desktop **（远期 · 规格保留）**

环境变量 `DEPLOYMENT_MODE=desktop`（实现时再引入）。与 self_host 分叉身份与前端路由；RAG 共用。当前代码**不**注册 `/meta`、`/settings` 桌面专用路由。

| 层 | self_host（当前） | desktop（远期） |
|----|-------------------|-----------------|
| 身份 | Cookie session | 隐式本机用户 |
| 前端路由 | `/`、`/admin`、`/library` | `/setup`、`/settings`、`/library` |
| 配置 API | `PUT /admin/settings` | `GET/PUT /settings` |

## 技术栈（冻结 · 当前阶段）

- 前端：Vue3 + Vite + Vue Router + Pinia
- 后端：Python FastAPI
- 数据库：PostgreSQL + pgvector；FTS `simple`
- 文件：本地磁盘 `FILES_DIR`；浏览器 PUT `/api/storage/{key}`
- **Embedding：** 本地（ONNX / sentence-transformers 等，实现时定）
- **Chat：** OpenAI 兼容 API（用户配置）
- 部署：Docker Compose（api + web + postgres）；可选 Caddy/Nginx HTTPS

明确不用：LangChain / LangGraph / LlamaIndex 当骨架；Redis；Celery；多租户 SaaS 框架；官方 OSS；SMTP。

## 前后端关系

- Vue 打同域 `/api`；Cookie session（当前）。
- 生产 `/` 静态、`/api` 反代；开发 Vite 代理。
- 上传：短时签名 PUT。

## 检索与质量（当前阶段）

**检索（现有 + 好用迭代）**

- 混合：pgvector（本地 embed 分数 `1 - 距离`）+ `tsv` FTS（`plainto_tsquery`）。
- 默认 **`RETRIEVE_K=8`**；合并后最多 8 段进 Chat。
- 门槛（实现本地 embed 后**须重标定**）：默认 `VECTOR_MIN_SCORE=0.28`、`VECTOR_STRONG_SCORE=0.38`（随模型调整）。
- **P1：** 多文件时 top-K **每文件至少 1 段**（当 ready 文件数 ≤ K）。
- **P1：** 扩展 summary/capability 问法识别 + Prompt。
- **P2：** rerank；Map-Reduce 多文档总结。

**分块（现有 + P1）**

- 当前：500 字滑动窗口 + 80 重叠；extract 后压空白。
- P1：Markdown 等保留段落/标题边界后再切。

## 备选方案

- **整文件塞进上下文：** 否。必须 RAG。
- **SQLite：** 否。pgvector 需 Postgres。
- **云端 Embedding 为默认：** 否（当前）；远期可作高级选项。
- **桌面 fork RAG：** 否。
- **公开注册 / SMTP / SaaS：** 否。

## 存储扩展（非官方 v1）

`storage.py` 抽象 `Storage`；v1 仅 `LocalStorage`。

## 数据模型

- `users`：id, email（登录名）, password_hash, is_admin, created_at
- `instance_settings`：id=1；**openai_api_key, openai_base_url, openai_chat_model**（当前 UI 必填）；Embedding 模型与维度由代码/`config` 固定（384），不入库
- `files` / `chunks` / `conversations` / `messages` / `citations`：同前；`chunks.embedding` 384 维 + `tsv`

删除文件、账号校验、bootstrap：同前（仅 self_host 种子管理员）。

## API

错误带 `code` + 按语言 `message`。

### 自托管 · 当前

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/auth/login` | 登录 |
| POST | `/auth/logout` | 登出 |
| GET | `/auth/me` | 当前用户 |
| GET/PUT | `/admin/settings` | **Chat 三项**（GET 含 Key，仅管理员） |
| GET/POST/PUT/DELETE | `/admin/users`… | 用户管理 |
| PUT | `/admin/me/password` | 管理员改密 |
| GET/POST/DELETE | `/files`… | 文件 |
| PUT | `/storage/{key}` | 直传 |
| GET/POST/PATCH/DELETE | `/ask/conversations`… | 对话 |
| POST | `/ask` | SSE 问答 |

### 桌面 · 远期

`GET /meta`、`GET/PUT /settings`；禁用 `/auth`、`/admin`——当前不注册。

## 关键流程

1. **上传：** 鉴权 → 类型/大小 → 哈希去重 → PUT → `complete` → extract → **本地 embed** → ready + tsv。
2. **提问：** 鉴权 → **本地 embed 问题** + FTS → 门槛 → SSE Chat。
3. **Chat 未配置：** `LLM_NOT_CONFIGURED`；**本地 embed 失败：** `EMBED_FAILED`（ingest/retrieve）。

## 横切

- 查询带 `user_id`；前端不长期暴露 Key；日志不含密码与全文。

## 风险

| 坑 | 如何避开 |
|----|----------|
| 云端 embed → 本地 embed 迁移 | `reset-dev-data.py` 或清材料重传；维度以 `config.default_embed_dim` 为准 |
