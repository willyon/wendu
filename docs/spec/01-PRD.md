# PRD（Product Requirements Document / 产品需求文档）· 问牍

产品名：**问牍**（英文品牌名 **Wendu**；仓库目录 `wendu`）。牍是文书；问的是你上传的那叠材料，不是全网。

## 对外一句话

上传 PDF、Word、PPT、表格或 Markdown 等文档，对着你的材料提问，答案带出处。

## 定位

**开源自托管知识问答**（非 SaaS）。材料与数据在部署者自己的服务器或本机；**对话（Chat）**走用户自配的 OpenAI 兼容 API；**向量（Embedding）**由部署包内置本地模型，无需用户配置 Embedding Key。无公开注册、无官方托管、无套餐配额。

### 当前阶段（代码与开源 v1 围绕此交付）

- **唯一实现形态：开源自托管 Web**（Docker / 本机部署 → 浏览器访问；登录、管理员、多用户）。
- **产品目标：好用**——克隆部署后能稳定完成「上传 → 材料内问答（出处）→ 材料外拒答」，检索与配置体验达到可开源水准，避免「小玩具」观感（见 `02#当前阶段·好用`）。
- **模型策略：** 本地 Embedding（默认 `multilingual-e5-small` 等价能力）+ 云端 Chat（管理页仅配 Key / Base URL / 对话模型）。

### 远期保留（规格保留、当前阶段不实现）

- **官方桌面安装包**（无登录、隐式单用户、`/setup` 等）：见 `02#主路径·桌面`、`04#部署模式·desktop`；**不在当前里程碑写代码**。

**两种交付（远期）仍共用同一 RAG 核心**；当前仅实现自托管分支。

## 谁

一种人：手头有几份说明、报告、笔记（PDF、Word、表格等），想问里面写了什么，并且要能核对原文。不是企业知识库管理员，也不是「什么都想问 AI」的闲聊用户。

- **自托管（当前）：** 为自己或少数人部署，可接受登录与建号。
- **桌面（远期）：** 本机个人使用、不想碰部署命令——以后再考虑。

## 问题

今天把文件丢给 ChatGPT 一类产品，也能总结、也能问。痛点是：回答常混进模型自己的知识，出处不稳定，材料也不在自己这边形成一份可再来的库。值得做成产品的点不是「更会聊」，而是 **只答这批材料、并能点回原文**。

## 目标

**核心（自托管当前阶段须满足）：**

- 上传支持的文档类型，处理完成后可提问。
- 回答只依据已处理材料；检索支撑不足时，界面明确说材料里没有，不把世界知识当答案。
- 每条关键结论带可点的出处（文件名 + 原文片段）。
- 下次打开仍能看到自己的材料和问答；原文件落在本地磁盘。
- **Embedding 本地内置**；**Chat** 配置写入 `instance_settings`（Key / Base URL / 对话模型）；界面中英可切换。
- **好用：** 见 `02#当前阶段·好用` 与 `04#检索与质量`。

**自托管 Web（当前实现与迭代方向）：**

- 种子管理员登录；管理页配置 **Chat**、创建普通用户、改密/重置/删用户。
- 多用户按 `user_id` 隔离。

**桌面安装包（远期 · 规格保留）：**

- 无登录页、无 `/admin`、无多用户；首次 `/setup` → 工作台等——**当前阶段不开发**。

## 非目标（明确不做）

- **官方 SaaS / 多租户托管**（代管用户账号与文件、公开试用站当正式产品、支付套餐）
- **当前阶段不做桌面安装包**（规格保留为远期）
- 和 ChatGPT 比谁更会总结、闲聊、写作、翻译、多轮角色扮演
- 用模型世界知识补全材料里没有的内容
- 多 Agent、工作流画布、任意网页抓取与「研究一下某某市场」
- Notion / 邮件 / 网盘同步、团队空间、分享链接
- 支付、套餐、公开自助注册、邮箱激活注册流
- 微信小程序、手机 App（可列入更远路线图）
- MCP、多模态（图问字、扫图）、语音；图片 OCR、扫描件 PDF OCR
- 老版 Word（`.doc`）；要求另存为 `.docx`
- 第二种登录、第二条主路径（生成待办清单、对照 JD 等）
- 第三种界面语言；把用户材料或出处翻译成界面语言
- 每用户文件数上限、每日提问配额、全站熔断
- 一次问答承诺「总结用户全部 N 份文件全文」（除非实现 Map-Reduce；当前见 `02#问答·能力边界`）
- 与自托管并行维护一套**独立 RAG / 第二套后端**

## 成功标准

**自托管（当前）：** 没看过设计的人，用 **自己的** 3 个文件，约 3 分钟内：登录 → 管理页配好 **Chat** → 上传完成 → 有依据问答 + 材料外拒答；**无需配置 Embedding**。

**桌面（远期）：** 同上主路径能力；起点改为安装 → 配置 → 工作台（无登录）——当前不验收。

## 约束

- **当前代码范围：** 仅自托管 Web；桌面相关规格**保留不删**，标注远期。
- 界面：浏览器响应式 Web；不做手机 App；不做官方 SaaS。
- **Chat：** OpenAI 兼容接口；Key 由管理页写入，前端不长期持有。
- **Embedding：** 部署包内置本地模型；用户不可配云端 Embedding（远期可选「高级：云端 Embedding」不在当前阶段）。
- 界面语言：第一版仅中英（`zh` / `en`）。
- 规格与代码在本仓库 `docs/spec/`。
