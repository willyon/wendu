# UI 交互 · 问牍

## 设计理念
遵循用户级 skill **`product-ui`（简约大方）**：少页、大留白、品牌先于功能；组件库只做控件，页面骨架自建。

本产品落点：入口浅纸色底 + 工作台近白底；墨绿一色；品牌衬线英雄级（中文「问牍」/ 英文 Wendu）；未登录入口无 App 顶栏；隐私一句脚注，不设 About；上传用原生控件；布局随屏宽自适应。

## 视觉约束
- 组件：页面骨架与上传区自建；不引入整站后台组件库
- 气质：留白多、层级少、装饰少；禁止霓虹、紫渐变、营销宫格、厚卡片堆叠
- 字体：品牌用衬线（Noto Serif SC / Source Serif 4）；正文与控件用 IBM Plex Sans
- 色：**入口页**浅纸色底（极淡层次 + 纸纹）；**工作台**近白平底 `#fafafa`、无纸纹；主色 `#2c4a3a`；不要刺眼纯白办公风，也不要暗黑；不要动图/强插画抢登录
- 布局：登录后顶栏（产品名 + **窄屏**材料/问答切换 + **用户头像下拉**）+ **工作台**主区；宽屏 **三栏**（左对话、中问答、右材料），不是后台侧栏菜单
- 语言：入口页右上角切中英；**登录后**语言切换在**用户头像下拉**内（用户名下方一行）。品牌名：中文「问牍」，英文 **Wendu**（界面 `brand` 随语言切换）
- **响应式 Web：** 桌面与手机浏览器均可良好使用（流体宽度、合理断点）；不做独立 App
- 文案：短、具体、不营销；动效仅轻入场，不作噪

## 页面清单
| 路由 | 目的 | 主按钮 |
|------|------|--------|
| `/` | 入口：左品牌承诺 + 右**仅登录**（移动端上下） | 登录 |
| `/login` | 同 `/`（兼容旧链） | 登录 |
| `/admin` | 管理：改自己密码、LLM Key、创建/列出用户 | 保存 / 创建 |
| `/library` | 工作台（资料库 + 问答同页） | 上传 / 提问 |

**仅 `/library` 一个工作台路由：** 宽屏左右同屏；窄屏顶栏 **资料库 / 问答** 为页内 Tab（不另开 `/ask`）。已登录访问 `/` → `/library`。旧路径 `/files`、`/ask` 重定向至 `/library`（`/ask` 会切到问答 Tab）。

## 逐页

### `/` 入口（`/login` 同页）
- **桌面：** 左右成一块居中构图（约 960 宽、右栏约 360、无竖分割线）；左品牌英雄级 + 说明 + 隐私；右表单；「登录」中等衬线标题；语言切换浮于右上
- **窄屏：** 上下成一块居中；品牌与表单以细分隔线衔接
- 无「开始」、无注册 Tab、无忘记密码
- 进页聚焦用户名（若已记住用户名则回填并聚焦密码）；密码可回车提交；校验：空值、用户名格式（2–64，字母数字及 @._-）
- **记住用户名：** 登录成功后将用户名写入 `localStorage` 并下次自动回填；**不**记录密码
- 字段校验红字在对应输入行下方；接口失败用顶部浮层提示
- 不要：功能宫格、对比表、独立说明页、App 顶栏、第三方登录、厚卡片、公开注册

### `/admin`
- 须管理员登录；**复用工作台顶栏**
- **进入管理：** 头像下拉 **管理**（顶栏不放管理入口）
- **管理页顶栏：** 仅 **工作台**，点击回到 `/library`；无内容区返回链
- **布局：** 无页内大标题；**横向 Tab**（**模型** / 账户 / 用户），进入管理页默认 **模型**
- **表单行：** 「名称 + 一条输入底线」，行间无分隔横线；提示文案放在标签旁或输入 placeholder
- **账户：** 新密码 + **确认密码**（至少 6 个字符，两次须一致），不必再填当前密码；保存成功后**立即退出并回到登录页**，用新密码重新登录
- **模型：** 一句总述（无页内大标题）；五字段均为**必填**；保存须五项齐全，成功后再次打开回显最新已保存值；标签旁 **ⓘ** hover 说明；可折叠「如何获取与填写？」
- **用户：** 上方创建用户（用户名 placeholder 提示格式）；下方用户列表；非管理员可重置密码或**删除**（确认后删账号并清空其全部材料）
- 接口失败 / 保存成功：顶部浮层提示（自写 Toast，类似 Message）；登录页字段校验仍在控件旁

### 工作台（`/library`）

**顶栏：** 品牌 + 窄屏 **资料库 / 问答** 页内 Tab（宽屏隐藏）+ 用户头像下拉（含 **管理**、语言、登出）。

**宽屏（≥960px）**
- **无任何文件时：** 整页仅居中上传区（不展示三栏）；**整页任意位置**可拖入 OS 文件上传
- **有文件后：** **左**对话列表 + **中**问答阅读流与粘底输入 + **右**材料上传与文件列表；三栏同屏；顶栏隐藏「资料库 / 问答」Tab
- **工作台任意位置**可拖入 OS 文件上传（与右侧虚线框等效）
- 列表中 **ready** 文件拖入中间提问框：仅限定提问范围（`application/x-wendu-file`），**不触发上传**
- 输入框上方可显示已选文件 chip（无选则检索全部 **ready** 文件）
- 无页内大标题；气质仍像书桌材料架，不要厚卡片墙

**窄屏（<960px）**
- 顶栏「资料库 / 问答」切换：**资料库** = 仅材料栏；**问答** = 上方对话列表 + 下方问答区
- **无任何文件时：** 不论当前 Tab，整页仅居中上传区（与宽屏空态一致）
- 完成文件点选可限定提问范围（拖放可选，不挡主路径）

**材料侧**
- **空态（整页）：** 上传区视口居中；透明底 + 极淡虚线；衬线「上传/拖入文件」；副文案说明可拖入**页面任意位置**
- **有文件后：** 左栏内上传收成顶部紧凑入口；下列表（仅列表顶部分隔线，行间靠间距）

**问答侧**
- **对话栏（左栏）：** 顶栏 **新建对话** 主按钮（图标 + 文案，ChatGPT 式）；下列表项单行标题 + 气泡图标；当前项浅底高亮；**重命名 / 删除** 在删除钮左侧并排，hover（窄屏常显）显示。点重命名：标题行内变输入，Enter/失焦保存，Esc 取消；点删除：站内确认框（与管理页删除用户同气质），确认后删
- **空态：** 中间区轻提示 + **粘底**输入（不与对话栏堆叠）
- **有对话后：** 上阅读流、下粘底输入；**多轮之间无横线**，靠间距区分；出处脚注式展开
- **流式回答：** 检索完成后答案逐字/逐段出现（类似 ChatGPT）；检索阶段仍显示「正在回答…」；**出处**在生成结束后才展示
- **答案排版：** 按 Markdown **预览**渲染（加粗、列表、行内代码等），不展示 `**` / `` ` `` 等源码符号；不做完整文档编辑器
- **自动滚动：** 流式变长时阅读区跟随滚到底；用户主动上翻阅读时不打断
- **终止回答：** 生成过程中主按钮变为「停止」，可随时中断；已生成内容保留并落库；**停止后问题回到输入框**（尚无出字时该轮从阅读流撤下）
- 不要：模型选择、温度、整页 ChatGPT 式侧栏、语音等聊天壳控件

**不做独立 `/about`。** 隐私一句放在入口左栏品牌下方。
