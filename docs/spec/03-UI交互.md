# UI 交互 · 问牍

## 设计理念

遵循用户级 skill **`product-ui`（简约大方）**：少页、大留白、品牌先于功能；组件库只做控件，页面骨架自建。

**共用气质：** 工作台近白底 `#fafafa`、墨绿主色 `#2c4a3a`；品牌衬线（中文「问牍」/ 英文 Wendu）；正文 IBM Plex Sans；上传原生控件；布局随屏宽自适应。

**当前阶段：** 仅 **自托管 Web** 的页面与交互；桌面相关章节 **（远期）** 保留供以后实现。

**按部署模式分叉入口（远期含桌面），共用工作台：** 自托管有登录页与管理页；桌面远期有 `/setup` 与设置。**当前**只实现自托管。`/library` 工作台 UI 为交付核心。

---

## 视觉约束（共用）

- 组件：页面骨架与上传区自建；不引入整站后台组件库
- 气质：留白多、层级少、装饰少；禁止霓虹、紫渐变、营销宫格、厚卡片堆叠
- 色：工作台近白 `#fafafa`；主色 `#2c4a3a`
- **响应式：** 浏览器与桌面壳内均可良好使用；不做手机 App；不做平行原生桌面 UI
- 文案：短、具体、不营销；动效仅轻入场

**自托管入口页：** 浅纸色底 + 纸纹；未登录无 App 顶栏；语言切换浮于右上。

**桌面配置页 `/setup`（远期）：** 气质对齐入口页；无登录表单。

## 页面清单

### 自托管 Web **（当前）**

| 路由 | 目的 | 主按钮 |
|------|------|--------|
| `/` | 入口：左品牌 + 右**仅登录** | 登录 |
| `/login` | 同 `/` | 登录 |
| `/admin` | 管理：改密、**Chat 配置**、用户 | 保存 / 创建 |
| `/library` | 工作台 | 上传 / 提问 |

已登录访问 `/` → `/library`。`/files`、`/ask` 重定向至 `/library`。

### 桌面安装包 **（远期 · 当前不实现）**

| 路由 | 目的 | 主按钮 |
|------|------|--------|
| `/setup` | **模型配置**（首次或未配齐时强制） | 保存并继续 |
| `/settings` | 修改模型（自 `/library` 进入） | 保存 |
| `/library` | 工作台 | 上传 / 提问 |

**无** `/`、`/login`、`/admin`。未配置时访问 `/library` → 重定向 `/setup`。已配置时 `/setup` 可手动进入（改配置）或从设置进入。

## 逐页

### 自托管 · `/` 入口（`/login` 同页）

- **桌面宽屏：** 左右居中（约 960 宽）；左品牌 + 隐私；右登录表单；语言右上
- **窄屏：** 上下堆叠，细分隔线
- 无注册、无忘记密码；记住用户名（`localStorage`），不记密码
- 校验与接口失败：字段下红字 / 顶部 Toast

### 自托管 · `/admin` **（当前）**

- 须管理员登录；顶栏仅「工作台」返回
- 横向 Tab：**模型** / 账户 / 用户；默认模型
- **模型 Tab：**
  - **必填三项：** API Key、Base URL、对话模型（**不**展示 Embedding 配置或只读说明）
  - 标签旁 **ⓘ**；可折叠「如何获取与填写？」
- **账户 / 用户：** 改密、建用户、重置、删除

### 桌面 · `/setup` **（远期）**

- **阻断式：** 保存成功前不可进工作台；**无「跳过」**
- 布局：品牌 + 一句说明 + 隐私脚注 + **Chat 三项表单**（与 admin 模型 Tab 同组件、同校验）
- 主按钮：「保存并继续」→ 成功后 `replace` 到 `/library`
- 语言切换：页内右上（与入口页类似）
- 不要：登录框、用户 Tab、账户 Tab

### 桌面 · `/settings` **（远期）**

- 从工作台顶栏 **设置** 进入
- 仅 **Chat 三项** + 保存

### 工作台 · `/library`

**自托管顶栏（当前）：** 品牌 + 窄屏 Tab + 用户头像下拉（管理、语言、登出）。

**桌面顶栏（远期）：** 品牌 + Tab + **设置** + 语言（无头像/登出/管理）。

**宽屏（≥960px）**

- 无文件：整页居中上传；整页可拖入 OS 文件
- 有文件：左对话 / 中问答 / 右材料；ready 文件可拖入提问框限定范围
- 流式回答、Markdown、出处、停止生成等同既有规格

**窄屏（<960px）**

- 顶栏 Tab 切换资料库与问答；空态与宽屏一致

**材料侧 / 问答侧：** 与现规格一致（对话栏、空态、粘底输入、出处脚注等）。

**不做独立 `/about`。** 隐私一句：自托管在入口左栏；桌面在 `/setup` 品牌下。
